# Original StudyPath demo handouts

Five authored two-page PDFs, one for each fictional demo subject. Created specifically for StudyPath presentation/testing, not downloaded third-party course material and not professor approved. Concepts, worked examples and short practice answers are included. No real student data.

Regenerate using `python android/tools/build-demo-handouts.py` (reportlab 4.x). Fonts are embedded from the existing app resources; their licenses are included in the app's assets/licenses directory. PDFs work offline and may be used to demonstrate OCR text checking and reviewer creation.
