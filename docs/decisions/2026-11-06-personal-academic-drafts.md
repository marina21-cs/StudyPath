# Personal academic drafts alongside reviewed policy tools

Status: accepted for the user-authorized 0.1.7 feedback implementation, 6 November 2026.

The published catalog can be empty, but students still need visible grade entry and planning tools. Add optional personal grading drafts and explicit course-ID linking to the existing UID-owned local subject records. Reuse GradeEngine for raw draft estimates; expose personal GWA arithmetic and independent what-if assumptions with clear labels. Keep published-policy capability gates unchanged.

A student can prepare/share a review copy, but cannot grant approval. Official conversion, retake rules, enrollment eligibility and approved labels still require trusted reviewed catalog evidence. Personal prerequisite links remain an unreviewed “requires all” map; no pass threshold is inferred from a grade.

Consequences: students can use the tools without a published course pack. Personal data has no cloud backup. Real reviewed academic acceptance remains open, and the local draft is not automatically promoted into a published policy. Optional fields preserve legacy workspace compatibility.
