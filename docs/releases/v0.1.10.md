# StudyPath 0.1.10 — shared Tide UI, flexible grading and PDF reviewers

Version code 11. [Download StudyPath.apk](https://github.com/marina21-cs/StudyPath/releases/download/v0.1.10/StudyPath.apk).

- Demo and personal workspaces share the native shell and main Study, Planner, Profile and material components. Header insets are applied before attachment; selected controls use readable Tide theme colors.
- Planner → Set up grading supports activities, quizzes, exams/tests, projects, homework and custom categories, percentage weights and assessment aggregation. Choose raw percentages, an explicitly configured linear numeric range or custom letter/numeric bands. Draft estimates stay separate from recorded final grades and GWA.
- Open an imported/downloaded personal PDF → Turn this PDF into a reviewer. Select up to five pages, check on-device OCR text, edit identification/cloze drafts or add manual original-page image cards, confirm and save. Practice offline, reveal answers, mark understanding, retry missed cards and return to the original source page. Add a dated review task to Planner.

Reviewer questions are extractive drafts, not AI-generated summaries or worked math. Cards/results stay on this device under the account; no generation service receives the PDF. One saved reviewer per PDF, up to 40 cards and 20 reviewers within the workspace limit. Replacing a reviewer requires confirmation and resets practice results. Deleting its PDF removes the reviewer. Review-task creation does not enable notifications.

This is a cloud-configured debug test APK using the existing signing certificate. Production Firebase acceptance remains separate; Privacy and Terms remain test-build notices.
