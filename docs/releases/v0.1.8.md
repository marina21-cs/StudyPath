# StudyPath 0.1.8 — Tide, demo and a simpler Planner

Version code 9. Native Kotlin/XML refinement from the approved five-slide proposal.

Download asset: [StudyPath.apk](https://github.com/marina21-cs/StudyPath/releases/download/v0.1.8/StudyPath.apk). Cloud-configured debug test build, signed with the same certificate as 0.1.7.

## What changed

- **Try the student demo** from Welcome or Profile/Settings. Explore fictional Alex Reyes's five subjects, 15 units, three tasks and nine authored notes without signing in. Demo has working task checks, grade examples, GWA inclusion, score estimates, scenarios, a prerequisite map, profile editing, reset and exit.
- **Planner: Overview / Subjects / Grades.** Tasks, subject management and academic tools each have a clear home. Reviewed school tools and existing policy checks remain available under Grades.
- **Profile and Settings.** Avatar initials, editable name, real study counts, appearance, reminders, storage, learning preferences, family sharing and account/sync controls.
- **Tide light, dark and system appearance.** The preference persists across app launches. Blue and neutral UI surfaces replace maximalist category colors; the StudyPath giraffe and native button feedback remain.
- **Privacy, Terms and About.** Included as test-build notices and app information. Final public-service policies/operator details remain pending.

## Data and academic boundaries

Demo records live in their own in-memory session, never in a real-account namespace. Reset/exit do not change the original account or its offline files. Appearance is an app preference shared across demo and normal screens. Closing demo discards fictional edits; configuration changes retain them, while process death can restart the demo.

Sample grades are illustrative. Personal grade drafts, GWA and map links do not grant institutional approval. Existing live reading, COR/PDF and reviewed-policy workflows retain their guards.
