# StudyPath 0.1.3 phone check

Install `StudyPath.apk` as an update to your existing app. Keep the installed app and its data.

## Main checks

- [ ] **Navigation:** switch between Study, Saved, Planner and Account. The selected icon has a small pill; labels stay readable. Scroll each screen: no right-edge scrollbar. Repeat with your phone's larger text setting.
- [ ] **Browse:** scroll to Browse topics. Every topic name fits; tapping one searches. Download course lessons is separate from your personal materials.
- [ ] **Subjects:** open **My subjects · PDFs & lessons** from Study or Saved. Add a subject. Use its selector to change subjects or edit the current one. Check that each subject has its own tasks/materials.
- [ ] **PDF:** choose Lessons & PDFs → Import PDF. Cancel once, then choose a real multi-page PDF. Turn on airplane mode, reopen it, move between pages, leave and return. The last page should be retained. PDFs must be unencrypted/renderable, at most 25 MiB and 500 pages.
- [ ] **Your lesson:** choose Create lesson / study card. Write a title, text, and optional question plus answer. Open it, try an answer, then Show answer / Try again. Use the ⋮ menu to edit or remove it.
- [ ] **Reading:** search Wikipedia, open an excerpt, then Read full article. Next/Previous and the page picker should work. Images and tables are available through the source link. Save the excerpt and a private note; reopen them offline. Full article availability offline is not guaranteed.
- [ ] **Manual planner:** open My subjects & tasks. Add a task and due date, edit it, mark it done, then unfinished. Restart the app and check it persists. Unfinished tasks appear in Planner even without a course pack.
- [ ] **Account:** outlined rows and chevrons should clearly indicate controls. Edit profile should show a name form, not onboarding. Save a name, return, and verify it. Your study & account → Edit learning preferences should open an editor without Skip or the welcome flow.
- [ ] **Backend continuity:** reconnect, save a reading/note, sign out, and sign back in with the same account. Confirm the name and saved work remain available. Official grade tools require a reviewed course pack; personal tasks do not unlock unsupported calculations.

Personal subjects, tasks, lessons and imported PDFs are **on this phone only**. They survive normal updates, but are not cloud backed up; uninstalling or clearing app data removes them. Personal task dates do not schedule notifications. Existing reading/lesson reminders remain separate.
