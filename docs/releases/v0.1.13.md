# StudyPath 0.1.13 — editable study notes and photos

Version code 14. [Download StudyPath.apk](https://github.com/marina21-cs/StudyPath/releases/download/v0.1.13/StudyPath.apk).

Subjects now have **Add material → Write note or add photos**. Write and edit notes, attach up to six photos with captions, and optionally add a question and answer for review. Personal workspaces also offer PDF file and PDF link import from the same menu.

PDFs have **Add note for this page** and a list of page notes. Each linked note can return to its source page; the original PDF stays unchanged. Notes and photos are saved privately on this device. Demo uses the same editor with temporary session data and its bundled PDF library.

Validation: 536 JVM tests across 61 suites; ten passing focused Android note, PDF, grading, navigation and theme checks; signed-in local Firebase smoke including note/photo persistence. The smoke preceded the final text-field and note-reader layout polish; the final focused checks cover that polished UI. Production Firebase and physical-device acceptance remain separate.
