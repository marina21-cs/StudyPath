# StudyPath 0.1.11 — semester grading and offline demo PDFs

Version code 12. [Download StudyPath.apk](https://github.com/marina21-cs/StudyPath/releases/download/v0.1.11/StudyPath.apk).

- **Planner → Set up grading** now starts with the grading system, then a category checklist and editable percentages. Review and apply to all current subjects. Existing assessment scores and final grades are preserved; incompatible scored categories block the entire change. Subject-specific adjustments remain available.
- **Study / Wikipedia** has a separate discovery card with more space. Optional topics and course lessons are behind one Browse control.
- **Demo → Saved** now starts with five real, offline, two-page PDF handouts—one per subject—followed by nine sample notes. Open a PDF and use the same on-device OCR, checked question drafts, answer reveal, source navigation and self-rated practice as the real app. Demo data remains isolated and is discarded on exit/reset.

The PDFs are original presentation samples, not professor-approved modules. Grading rules are personal drafts. The reviewer creates extractive question drafts; it does not invent summaries, answer options or worked solutions.

Validation: **531 JVM tests**, **seven focused Android tests**, and the expanded **signed-in local Firebase smoke** passed. All five PDFs opened through Android PdfRenderer; the Data Structures PDF completed the shared OCR/reviewer path. Light/dark header and navigation checks passed. All 333 Android source files matched between the verified source snapshot and cloud build.

This is a cloud-configured debug test APK with the same signing certificate as 0.1.10. Production Firebase acceptance and physical-device/TalkBack checks remain separate from local emulator verification. Full receipts: `implementation/phases/03-validation/semester-demo-0111/README.md`.
